# Third-party notices and research provenance

Original contributions and third-party material must be distinguished when reusing this academic repository. Dependency packages retain their own licenses; package-manager license metadata does not by itself license every file in this repository. No new repository-wide license is granted by this maintenance pass.

The video/transcript pipeline in the related source identifies [nestyme/Subtitles-generator](https://github.com/nestyme/Subtitles-generator) as an original source. Underthesea provides the pretrained topic classifier; Sumy supplies summarization algorithms where used. Retain upstream notices and review their licenses before redistribution.
